**Project**: Fraud Detection Dashboard

- **Purpose**: A frontend demo dashboard for monitoring card transactions and visualizing a simple ML-style fraud scoring model in real time. The UI simulates transaction inputs, runs a local heuristic model, and displays trends, distribution, alerts, and recent transactions.

**Tech Stack**:
- **Framework**: `Next.js` (app router, client components)
- **Language**: `TypeScript` + React
- **Styling**: `Tailwind CSS` (custom theme in `app/globals.css`)
- **Charts**: `recharts` for bar & pie charts
- **UI utilities**: `lucide-react`, `clsx`, `cmdk`, `date-fns`, and several Radix primitives (installed but not all necessarily used in this demo)

**Quick Start (local)**

- Prerequisites: Node (recommended 18+), `npm` or `yarn`.
- From the project root run:

```zsh
# Install deps
npm install

# Run development server (default: http://localhost:3000)
npm run dev
```

- Build for production and start:

```zsh
npm run build
npm run start
```

**What you'll see**
- A single-page dashboard at `/` (rendered by `app/page.tsx`) displaying:
  - Summary metrics (`components/summary-cards.tsx`)
  - Transaction trends (`components/transaction-trends.tsx`) - bar chart
  - Transaction distribution (`components/transaction-distribution.tsx`) - pie chart
  - Model performance card (`components/model-performance.tsx`) — placeholder UI
  - Fraud alert card (`components/fraud-alert.tsx`) — shows latest flagged transaction
  - Recent transactions table (`components/recent-transactions.tsx`)
  - Right sidebar (`components/right-sidebar.tsx`) where you can enter transaction details and press **Run Model** to simulate a prediction

**Important code flows / architecture**
- `app/layout.tsx` and `app/globals.css` set the base layout and dark theme variables.
- `app/page.tsx` mounts the top-level `Dashboard` component (`components/dashboard.tsx`).
- `Dashboard` holds UI state: `transactions`, `trendData`, `distributionData`, and the latest `alertTx`.
  - It passes `onModelRun` to `RightSidebar`, which lets the sidebar submit a simulated prediction back to the dashboard.
- `RightSidebar.runModel()` implements a local heuristic scoring function (a simple rule-based score built from amount, merchant type, country, hour, previous declines, and card age). It computes a probability (0–100) and determines fraud when probability >= 60. It then creates a `tx` object and calls `onModelRun(tx)`.
- `Dashboard.handleModelRun(tx)` updates `transactions`, appends/upserts monthly `trendData`, recalculates distribution percentages, and sets `alertTx` which drives `FraudAlert`.

**Development notes & suggestions**
- The current model is purely client-side and heuristic. To integrate a real model:
  - Add an API route under `app/api` (or a separate backend) to call a trained model/service.
  - Persist transactions to a DB (e.g., Postgres) and load historical trend data from there.
- Consider adding tests (Jest/React Testing Library) for component rendering and model behavior.
- Add linting & commit hooks (ESLint, Prettier, Husky) for consistent code style.
- Dockerize the app for repeatable deployments.

**Troubleshooting**
- If charts don't render ensure `recharts` is installed (it is already listed in `package.json`).
- If Tailwind utilities do not apply, confirm `tailwind.config.ts` and `postcss.config.js` are present and your Next.js version supports the used Tailwind config.
